Let an AI agent run it

The trained models are wrapped as tools. An LLM agent decides when to call them, reads the result and answers in plain language. Any agent that supports tools, such as Claude Code, Codex or Gemini CLI, can connect through MCP.

  1. You ask“Should engine 49 go in for service?”
  2. LLM agentChooses a tool and fills in its arguments
  3. Tool callpredict_rul(engine_id=49) over MCP or HTTP
  4. RUL modelGradient Boosting returns cycles left
  5. AnswerThe agent explains it and recommends an action

Press “Run the agent” to watch it call the tools.

Demo agent: every tool call and number is a real request to this API. The wording of the thoughts and the final answer is a template, because no LLM runs inside this page.

Edit the sensor readings

How accurate are the models?

Official NASA test set, 100 engines. MAE and RMSE are errors in cycles, so lower is better. R² is higher-is-better.
